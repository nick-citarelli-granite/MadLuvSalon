# Madd Luv Salon & Beauty Lounge

Static brochure page for Madd Luv Salon & Beauty Lounge.

## Open locally

Open or drag `MaddLuvSalon-Brochure.html` into a browser.

No install step is required. The page is standalone HTML/CSS and links booking buttons to GlossGenius:

```text
https://maddluvsalon.glossgenius.com/book
```

## Files

- `index.html` redirects to the brochure page for simple hosting.
- `MaddLuvSalon-Brochure.html` contains the mobile-first brochure site.

## Notes

- Public salon details and images are sourced from Madd Luv Salon's GlossGenius presence.
- No local image assets are required for the brochure page.
